# CEMM — Antigravity 입력 패키지

작성: 2026-10-16 / 목적: 치매 환자 외장 기록·연속성 보조 프로토타입과 학술 포트폴리오

## 처음 읽을 순서
1. `context/PROJECT_MEMORY_original.md`: 기존 프로젝트 기록(원본 보존). 일부 구버전 항목은 아래 최신 결정과 충돌할 수 있음.
2. `spec/ANTIGRAVITY_INSTRUCTIONS.md`: 실제 개발 작업 지시, 최신 요구사항과 제한.
3. `references/SOURCES.md`: 외부 자료 링크, 확정/추가/보류 구분.
4. `references/RESEARCH_MAPPING.md`: 근거 → 기능 → 검증 지표 연결.
5. `references/sources.json`: 도구용 구조화 참고문헌 목록.

## 최상위 원칙
- **기억 복원 또는 치료 효과를 주장하지 말 것.** 과제는 개인 기록과 맥락 연속성의 보조.
- 모든 녹취와 개인 데이터를 공개 저장소, 로그, 외부 LLM에 자동 전송하지 말 것.
- 개인의 자율성·현재 의사를 최우선으로 두고, 외부 기록이 환자의 직접 기억이라는 확신을 심지 말 것.
- 대화 전체 저장 금지: 사용자 승인 가능한 **정보 블록**만 저장.
- 하드웨어는 현 단계 범위 밖. 소프트웨어 알파만.

## 구성 파일의 성격
이 패키지는 기존 대화 및 공식 자료에서 추린 **링크·요구사항·개발 해석**이다. 논문/기관 문서를 전문 복제한 파일이 아니다. 정확한 문구와 도표는 원문을 확인해야 한다.
