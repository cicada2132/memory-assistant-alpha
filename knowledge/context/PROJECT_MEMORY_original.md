# 치매 환자 외장 기억 보조 AI — 프로젝트 핵심 기록

> 버전: 0.1 | 작성일: 2026-10-16 (KST) | 상태: 초기 핵심 정리
> 목적: 새 채팅이나 다른 AI 환경에서도 프로젝트의 목표·결정·쟁점을 일관되게 이어가기 위한 기준 문서.
> 이 문서는 연구 노트 및 개발 설계 초안이며, 임상적 효능이나 적법성이 검증되었다는 뜻이 아니다.

## 1. 프로젝트 목적
치매 환자가 최근 사건을 잊더라도 외부 기억 시스템이 사건의 시간적·맥락적 연속성을 유지하고, 환자가 현재 상황과 자신의 의도·관계·진행 중인 활동을 이해하도록 보조한다. 목표는 기억 저장 자체가 아니라 **자기 정체성, 의사결정, 일상 활동 및 인간관계의 지속을 지원하는 것**이다.

이 프로젝트는 포트폴리오를 겸하며, 사회복지·케어 AI·AI의 인간 중심적 활용에 관한 학술적 근거와 실현 가능한 프로토타입을 함께 지향한다. **AI는 인간의 생각과 선택을 대체하지 않고 돕는 도구**라는 방향을 유지한다.

## 2. 확정된 핵심 요구사항
1. **기억의 연속성 보조**: 사용자가 30분 전 사건을 기억하지 못하더라도, 외부 시스템은 사건의 순서, 배경, 관련 인물, 실행한 행동, 현재 미완료 과제와 다음 행동을 연결해 설명한다.
2. **외부 기억의 주체적 활용**: 사용자가 외부 기록을 자신의 삶의 일부로 받아들일 수 있도록 돕되, 실제 자전적 기억과 AI가 제시한 기록을 무분별하게 동일시하거나 강요하지 않는다.
3. **정체성·현실검증의 균형**: 외부 기억의 편입이 환자의 고유한 기억, 자기감, 현실검증을 침해하지 않도록 경계를 설계한다.
4. **활동 지속 지원**: 인지적·신체적·사회적 활동을 그만두면서 발생할 수 있는 기능 저하의 악순환을 줄이도록 일상 과제와 참여를 보조한다.
5. **개인 데이터 우선 통제**: 사용자 중심의 사적 공간에 저장·처리하고, 꼭 필요한 최소한의 가공 정보만 승인된 외부 AI/전문가와 공유하는 구조를 우선 검토한다.
6. **개인 운영 가능성**: 전문 관리자에 의존하는 중앙 데이터베이스보다 개인이 통제할 수 있는 폐쇄적 저장·접근 구조와 개인 사이트/앱 구현 가능성을 탐색한다.

## 3. 제안된 시스템 동작 흐름 (설계 가설)
`입력(음성·사용자 기록·일정 등)` → `기기 내 처리/민감정보 필터링` → `시간순 이벤트 기록` → `맥락·인물·의도·미완료 작업 연결` → `현재 상황 재구성` → `사용자에게 출처와 불확실성을 함께 제시` → `사용자 선택·교정 반영`

- **이벤트 데이터**: 사건 ID, 발생·기록 시각, 출처, 관련 인물, 행위, 사용자 의도, 후속 과제, 완료 상태, 신뢰도, 수정 이력.
- **기억 분류(제안)**: 자전적/의미/절차적 기억, 감정·애착 단서, 사회적 관계, 최근 사건과 진행 중인 목표를 구분한다.
- **출력 원칙**: 기록에 있는 사실, 모델의 추론, 사용자·보호자 제공 정보, 불확실한 정보를 명시적으로 구별한다.
- **현재 상태 계산**: 단순 검색이 아니라 `이전에 무엇을 하려 했는가? → 어디까지 했는가? → 무엇을 확인해야 하는가?`를 복원하는 기능을 지향한다.

## 4. 연구 중심 질문
- 기억이 자아 정체성을 구성하는 방식과 그 최소 조건은 무엇인가?
- 어떤 기억 능력과 감정·애착 단서가 치매 진행에 따라 상대적으로 보존되는가?
- 외부 기록을 '내 기억'으로 활용하는 것은 언제 유익하며, 언제 잘못된 확신·의존·자아 혼란을 초래하는가?
- 환자의 주관적 경험과 자기결정권을 유지하면서 보조 기억을 제공하는 인터페이스는 어떤 형태인가?
- 기억 보조가 실제 일상 기능, 활동 참여, 삶의 질, 돌봄 부담에 어떤 영향을 미치는가?

### 관련 연구 출발점
- Richard Heersmink (2022), *Preserving Narrative Identity for Dementia Patients: Embodiment, Active Environments, and Distributed Memory*, **Neuroethics**. DOI: https://doi.org/10.1007/s12152-022-09479-x
- 위 논문의 프로젝트 관련 주장은 원문을 직접 대조하여 별도 연구 노트에 근거와 한계를 기록한다. 특정 효과를 검증된 사실로 단정하지 않는다.

## 5. 반드시 해결할 안전·윤리 쟁점
- **동의 없는 상시 녹음은 확정 설계가 아님**: 음성 인식을 활용한 자동 기록 아이디어가 논의되었으나, 환자 및 주변인 동의, 녹음 관련 법률, 민감정보 처리 및 철회 가능성을 먼저 검토해야 한다. 비밀 수집을 기본값으로 구현하지 않는다.
- **당사자 우선**: 사전 동의, 상황별 명시적 알림, 가능한 범위의 현재 의사 확인(assent), 보호자·전문가 권한 분리, 거부·일시 중지 기능을 설계한다.
- **기억 오염 방지**: AI 생성 서술을 환자의 직접 경험으로 단정해 제시하지 않는다. 외부 기록은 검증 가능한 출처와 정정 가능성을 가져야 한다.
- **프라이버시**: 로컬 우선 처리, 최소 수집, 암호화, 접근통제, 보존기간, 삭제·내보내기 기능을 검토한다.
- **임상 안전**: 의학적 판단이나 긴급 대응을 독자적으로 대체하지 않는다. 실사용 전 전문가·사용자 참여 평가가 필요하다.

## 6. 단계별 로드맵
- [ ] 1단계: '기억'과 '기억의 연속성'의 작업 정의 및 인지과학·철학·사회복지 근거 수집
- [ ] 2단계: 환자/보호자/전문가별 시나리오, 실패 사례, 동의·권한 요구사항 정리
- [ ] 3단계: 최소 이벤트 스키마 및 시간·맥락 연결 메모리 모델 설계
- [ ] 4단계: 가상의 데이터로 연속성 복원 알고리즘 및 평가 지표 시험
- [ ] 5단계: 로컬 우선 프로토타입(개인 접근 웹/앱, 데이터 저장·검색·정정)
- [ ] 6단계: 잘못된 기억의 생성, 사생활 침해, 과도한 의존을 막는 안전장치 검증
- [ ] 7단계: 학술적 포트폴리오 작성(선행연구, 방법론, 구현 결과, 한계)

## 7. 논의 상태 구분
- **확정 방향**: 연속성 보조, 주체성·정체성 균형, 활동 지속, 로컬 우선, 인간 중심 AI.
- **미확정 설계**: 센서·음성 입력 방식, 디바이스·모델 선택, 외부 AI 연계 범위, 데이터 보존·권한 정책.
- **검증할 가설**: 외부 기억이 기억 공백에 따른 혼란을 줄이고 일상 기능과 정체성 유지에 도움을 줄 수 있다는 가설. 실증 결과가 나오기 전까지 성과로 표현하지 않음.

## 8. 문서 관리 규칙
1. 새 대화에서 **확정된 요구사항**과 **아이디어/가설**을 구분한다.
2. 변경 시 날짜, 변경 이유, 영향받는 기능을 함께 남긴다.
3. 확정된 내용만 이 파일 본문에 반영하고, 연구 근거는 원문 출처와 확인 상태를 기록한다.
4. 자동 작성된 업데이트는 검토 후 수동 반영한다. 다른 버전의 문서가 병존하면 기준 버전을 명확히 표시한다.
5. 민감한 환자 사례와 실명, 녹취, 인증정보를 이 프로젝트 노트에 직접 붙여넣지 않는다.
