## 2. 이번 작업의 범위

공개용 소개·설계·연구·검증·시연·개발 이력을 작성했다. 2026-10-22 사용자 승인에 따라 문서를 GitHub에 반영했다. 앱 소스 수정·배포·외부 AI 호출은 포함하지 않는다. 기존 업로드 문서와 기존 개발 로그는 덮어쓰지 않았다.

## 3. 패키지 구성

- `README.md`: 저장소 루트의 프로젝트 소개.
- `docs/`: 공개 설명용 상세 문서 12개.
- `examples/demo_261022_090000_original.txt`: 실제 개인자료가 아닌 합성 TXT.
- `evidence/mock-tests-20261022.txt`: 이번에 재실행한 모의 테스트 로그.
- `PACKAGE_GUIDE.md`: 문서 구성과 관리 안내.

최초 전달물은 문서 추가·교체용 ZIP이었다. 현재는 문서와 실행 코드를 같은 저장소에서 확인할 수 있다. 문서의 파일명·함수명은 이 저장소 기준이다.

## 4. 자료를 공개용으로 다듬은 기준

실제 개인 대화·의료정보·계정 이메일·API 키·개인 폴더 경로를 새 문서에 넣지 않았다. 기존 개발 로그의 Script ID·배포 ID는 소개에 필요하지 않아 옮기지 않았다. 개인 배포 URL을 공개 체험 링크로 오인하게 제시하지 않았다.

연구 자료는 짧게 재서술하고 원문 링크를 제공한다. 캐릭터 자료의 CC BY 4.0 고지를 유지해야 하며 저장소 전체의 코드 라이선스는 별도 결정 대상이다.

## 5. 이번 검사 범위

기존 모의 테스트 25개 통과, 지식·캐릭터 생성 문자열과 소스 문서의 일치, 문서 내부 링크·패키지 파일 확인을 수행했다. 브라우저 레이아웃·실제 클라우드·환자 평가를 수행한 것으로 확대 해석하지 않는다.
