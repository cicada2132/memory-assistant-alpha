# 개발 결정과 변화 이력

## 1. 기록의 우선순위

현재 동작은 커밋된 소스와 재실행 검사로 판단한다. 개발자가 나중에 정한 범위는 초기 문서보다 우선한다. 과거 배포·화면 확인은 `PROJECT.md`의 보고 이력으로 남기되 이번에 재확인한 결과와 구분한다.

## 2. 주요 변화

| 시기/단계 | 결정 또는 변화 | 의미 |
|---|---|---|
| 초기 철학 논의 | 기억·자아·외부 기록의 관계 탐색 | 기록을 삶의 일부로 활용하되 현재 의사를 대체하지 않는 방향 |
| 2026-10-16 초기 기록 | PROJECT_MEMORY v0.1 작성 | 목표·연구 질문·로컬 우선 설계 초안 |
| 같은 날 범위 조정 | 하드웨어 제외, 활동 악화 예방은 보류 | 소프트웨어와 개인 기록에 집중 |
| 초기 알파 이력 | 대화 UI·녹음, Python/SQLite 수집기 논의·산출물 보고 | 현재 GAS와 별도 계보. 이번에 재검사하지 않음 |

| 원칙 문서 연결 | knowledge 문서들을 systemInstruction에 포함 | 상담 태도와 금지사항을 코드와 연결 |

| 2026-10-22 문서 통합 | 실제 코드·25개 테스트·설계 이력을 대조 | 해커톤/포트폴리오 문서 패키지 작성 |

## 3. 충돌을 어떻게 정리했는가

| 이전 표현 | 이번 문서의 기준 |
|---|---|
| 활동 지속 지원을 확정 목표로 기재 | 기능 악화 예방은 보류. 현재 할 일 조회 기능과 효과 목표를 구분 |
| 원문을 보존하고 모두 DB에 저장 | 원문은 별도 출처로 남을 수 있지만, 현재 TXT 블록 DB에는 선택 정보만 저장 |
| OpenAI 키·17개 테스트·미배포 | 현재 소스는 Gemini, 이번 모의 검사 25개 통과, 과거 배포 이력 별도 존재 |
| 키가 있으면 외부 AI 동작 | 활성 플래그와 동의도 필요 |
| 단순 단어 검색만, 날짜·조사 미구현 | 현재 일부 조사·날짜 규칙 구현. 의미 검색·정교한 날짜 정규화는 미완 |
| 음성 입력 없음 | 현재 상담 UI에 SpeechRecognition 코드 존재. 실제 동작·외부 처리 검토 필요 |
| 모리 문서만 있고 코드 연결 없음 | 현재 Character.gs·Counsel.gs·Index.html에 연결 |
| 로컬 우선 구조 | 장기 방향. 현재 GAS/Drive 알파를 오프라인으로 표현하지 않음 |
| 저녁 자동분석·하루 노트 자동 저장 | 저녁 정리 화면과 선택 저장은 구현. 시간 예약 전체 흐름과 Markdown 자동 저장은 미확인 |

## 4. 원칙 문서와 제품 동작의 후속 정합성

이번 패키지는 공개 설명용 문서다. 런타임 프롬프트에 포함되는 `knowledge/context/PROJECT_MEMORY_original.md`는 바꾸지 않았다. 따라서 공개 문서에서 보류로 정리한 목표와 런타임 원칙 문서의 문구를 후속 작업에서 대조해야 한다. 프롬프트가 달라질 때는 상담 응답 평가도 다시 필요하다.

## 5. 관련 실험의 경계

별도로 논의한 웹 UI 자유 이동 고양이는 크기 1.5배, 시작 10초 커서 추적, 공으로 유인, 더블클릭 시 공 던지기 표시 등의 요구를 가진 UI 실험이다. 현재 기억 보조 앱의 모리는 상담 패널 SVG와 캐릭터 설정이다. 동일 기능으로 통합됐다는 증거가 없어 핵심 구현 성과에 합치지 않는다.
