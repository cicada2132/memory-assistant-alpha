# 구현 현황과 평가 증거

기준일: 2026-10-22 KST. 검사 대상 커밋: `e22860fe3674ec74e70fca6e7617104424fdbc04`.

## 1. 이번에 직접 확인한 결과

`node tests/run.mjs`를 저장소 파일의 로컬 사본에서 실행하여 **25/25 통과**했다. 결과는 [테스트 로그](../evidence/mock-tests-20261022.txt)에 있다. Google 서비스와 Gemini 응답은 모의 객체로 대체되었고 실제 외부 API는 호출하지 않았다.

`buildKnowledge()`와 `buildCharacter()`를 직접 호출해 생성 문자열과 커밋된 파일을 비교했다. 끝 개행을 정규화한 기준으로 둘 다 일치했다. 원본 문서가 생성 파일에 포함되는지 확인한 것이며 지침의 임상 적절성을 검증한 것은 아니다.

## 2. 모의 테스트가 다루는 영역

| 영역 | 확인 내용 |

| 파싱·초기화 | GAS/프런트 스크립트 구문, 반복 setup |

테스트 수는 품질 점수나 코드 커버리지 수치가 아니다. 테스트가 없는 경로도 있고, 실제 Google 환경의 제약은 재현하지 않는다.

## 3. 과거 이력과 현재 확인을 분리

`PROJECT.md`에는 2026-10-16 setup·Drive 폴더 생성·배포 버전 7·모의 화면 확인 이력이 기록되어 있다. 이번 작업에서 해당 배포를 열어 검사하거나 Google 관리 화면을 확인하지 않았다. 따라서 “배포 이력 있음”으로 쓰며 “현재 실서비스 정상 운영 확인”으로 표현하지 않는다.

초기 대화에는 Python 수집기 5개 테스트, 브라우저 녹음 알파 등의 보고가 있다. 이번 저장소와 동일한 산출물인지, 현재 재실행 가능한지는 확인하지 않았다. 현재 25개 테스트와 합산하지 않는다.

## 5. 남아 있는 구체적 문제

1. **RECORDS/BLOCKS 분리:** 음성 전사 결과가 현재 블록 검색·상담에 자동 편입되는 과정은 별도 구현·검증이 필요하다.
2. **시각 의미:** 녹음시각과 실제 사건시각이 다를 수 있다. 표시와 정규화 정책이 필요하다.
3. **검색 한계:** 일부 조사·상대 날짜 규칙은 있으나 동의어와 복잡한 날짜 해석은 미완이다. “아까/N분 전”은 최근 3시간 범위로 처리한다.
4. **후보 누락·화자:** 정규식으로 중요한 내용을 놓칠 수 있고, 화자가 당사자인지 자동 확정하지 못한다.
5. **파생 필드 정합성:** 본문 정정 후 기존 분류·인물·장소가 낡은 값으로 남을 수 있다.
6. **원문 보유:** 블록 삭제가 INBOX·백업·내보내기·제공업체 측 삭제를 의미하지 않는다.
7. **음성 입력:** 실제 마이크·권한·GAS 프레임 제약, 브라우저별 동작 미검증.
8. **자기정보·상담:** 프롬프트의 비강요 원칙이 실제 응답에서 지켜지는지 평가 필요.

## 6. 후속 평가 계획 — 결과가 아닌 제안

합성 시나리오 20개를 만들고, 정답 출처·계획 상태·불확실성을 사람이 먼저 정한다. 정상 질문과 기록 없는 질문, 화자 충돌, 오래된 선호, 정정, 삭제, 동의 거절 사례를 포함한다.

| 지표 | 계산/확인 방법 | 현재 값 |
|---|---|---|
| 검색 적중 | 정답 블록이 상위 5개에 포함된 질문 / 정답이 있는 질문 | 미측정 |
| 근거 없는 진술 | 입력에 근거가 없는 사실 문장 / 평가한 사실 문장 | 미측정 |
| 승인 전 저장·전송 | 거절·미승인 시나리오에서 발생한 횟수 | 모의 일부 경로만 검사 |
| 교정·삭제 성공 | 변경 후 재조회와 관련 상태 확인 | 모의 일부 경로만 검사 |
| 조작 부담 | 과업 완료까지 걸린 시간·조작 수·건너뛰기 | 미측정 |
| 사용자 주체성 | 과거 기록 거절·현재 선택 변경 가능 여부 | 사용자 연구 미실시 |

이 수치들을 먼저 채운 뒤 효과나 완성도를 평가한다. 정체성 유지·삶의 질·돌봄 부담은 별도 연구 설계가 필요한 결과변수다.
