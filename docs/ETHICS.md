# 자기결정과 프라이버시

## 1. 설계 원칙과 실제 구현을 구분한다

| 원칙 | 현재 장치 | 남은 한계 |
|---|---|---|
| 기록의 소유권과 통제 | 개인 계정 확인, MYSELF manifest, 수정·삭제·내보내기 | 실제 배포 접근통제는 별도 검사 필요 |
| 기억 오염 완화 | 출처 구분, 없는 사실 생성 금지 프롬프트 | 프롬프트 준수·환각 방지 보증 아님 |
| 자기정보 갱신 통제 | 제안→승인/수정/거절, 버전 충돌 검사 | 사용자 이해도·동의 능력 평가 미실시 |
| 데이터 최소화 | TXT 후보 중 선택한 문장만 블록 저장 | 원본 TXT·음성·기존 RECORDS는 별도 보유 |
| 외부 전송 통제 | 기본 비활성화, 동의, 미리보기 편집, 텍스트 가림 | 모든 경로의 완전 비식별화 아님 |
| 중단과 거절 | 선택 저장·건너뛰기·거절 | 실제 UI에서 당사자가 쉽게 찾는지 미평가 |

## 2. 기록과 사람이 충돌할 때

“기록이 맞고 당신이 틀렸다”고 정리하지 않는다. 기록이 잘못되었거나, 전사가 틀렸거나, 과거와 현재의 생각이 다를 수 있다. 출처를 함께 확인하고 교정·보류할 수 있게 한다. 과거에 좋아했다고 기록된 음식이나 활동을 지금 선택하도록 압박하지 않는다.

당사자의 발화, 다른 사람의 설명, AI의 해석은 서로 대체할 수 없다. 감정을 추정해 사실로 저장하거나, 기억나지 않는 일을 기억하도록 유도하는 것을 성과로 삼지 않는다.

## 3. 전송 경로별 실제 차이

- 텍스트 검색·분석·상담은 미리보기와 일부 연락처/등록 이름 가림을 사용한다. 주소·맥락으로 식별되는 정보·등록되지 않은 이름 등은 남을 수 있다.
- 원음 전사는 동의 후 원음 자체를 Gemini로 보낸다. 텍스트 가림은 원음의 발화 내용을 제거하지 않는다.
- 상담의 후속 턴은 승인한 기록, 대화 이력, 새 말이 포함된다. 앱 서버에서 대화를 저장하지 않는 것과 제공업체의 보존 정책은 별개의 문제다.
- 음성 출력은 코드에서 기기 내장 한국어 음성을 선택한다. 음성 입력은 브라우저 SpeechRecognition 구현에 따라 외부 처리가 일어날 수 있다. 두 기능을 모두 오프라인이라고 소개하지 않는다.
- Google Drive 저장 자체가 클라우드 처리다. 개인 전용이라는 설정을 완전 로컬 또는 종단간 암호화와 혼동하지 않는다.

## 4. 녹음과 공개 데이터

현재 구현은 사용자가 올린 파일을 처리한다. 무동의 비밀 상시 수집을 확정 요구사항으로 두지 않는다. 실사용 조건과 관련 절차는 별도 검토 대상이며, 이 문서는 법률 검토 결과가 아니다.

공개 저장소·해커톤에는 합성 사례를 사용한다. 실제 대화록, 가족 정보, 연락처, 의료자료, API 키는 시연 자료에 넣지 않는다. 본 문서 패키지의 TXT는 새로 작성한 합성 데이터다.

## 5. 캐릭터의 역할

모리는 상담사나 사람이 아닌 고양이 캐릭터다. 쉬운 존댓말, 짧은 질문, 한 번의 괄호 행동 표현을 사용하도록 설정했다. 캐릭터는 대화 태도를 보조하며, 기록 근거와 사용자 선택보다 우선하지 않는다. 사용자의 감정적 의존이나 신뢰 상승은 측정된 결과가 아니다.

원본 Mori 자료의 출처·라이선스·변경 고지를 보존한다. 기존 캐릭터 파일의 위기 대응 문구는 별도 검토 대상이며, 이번 정리는 위기 대응 기능의 품질이나 최신 연락 체계를 검증한 작업이 아니다.
