# 프로젝트 배경과 범위

## 1. 출발점

이 프로젝트는 “기억이 사라질 때 무엇이 나를 이어 주는가?”라는 질문에서 시작했다. 개발자가 지향하는 것은 기억을 완벽히 복제하는 장치가 아니라, 일상의 기록을 더 편하고 꼼꼼하게 남기고 다시 이해하도록 돕는 도구다. 결과물은 사회복지·케어 AI·인간 중심 기술을 연결하는 학술적 포트폴리오를 목표로 한다.

기록이 있다는 것과 그 기록을 자신의 삶에 의미 있게 활용하는 것은 다르다. 사용자는 외부 기록을 자신의 삶의 일부로 받아들일 수 있지만, AI가 제시하는 설명에 끌려 원래의 기억이나 현재 의사를 포기해서는 안 된다. 프로젝트는 이 편입과 대체 사이의 경계를 탐색한다.

## 2. 작업 정의

| 용어 | 이 프로젝트에서의 의미 |
|---|---|
| 기록 | 발화·전사·관찰·사용자 입력 등 출처가 있는 외부 정보 |
| 기억 | 당사자의 경험과 회상을 포함하는 개념. DB 저장값과 동일시하지 않음 |
| 정보 블록 | 사용자가 저장 대상으로 선택한 문장과 출처·시각·상태의 묶음 |
| 연속성 보조 | 이전 사건·의도·미완료 작업을 다시 확인할 수 있게 하는 기능 목표 |
| 서사적 정체성 | 사람이 자신의 삶을 연결해 이해하는 연구상의 관점 |
| 개인 통제 | 저장·수정·삭제·전송·자기정보 갱신을 사용자가 통제하는 방향 |
| CEMM | 기존 자료에서 사용한 연속형 외장 기억 프로젝트의 작업 명칭. 검증된 임상 모델 이름이 아님 |

## 3. 대상과 사용 상황

장기적으로는 치매로 기억 공백을 겪는 당사자를 위한 도구를 지향한다. 현재 알파는 개발자와 동의한 성인이 합성 데이터 또는 적절히 처리한 개인 기록으로 기술적 동작을 검증하는 단계다. 보호자·전문가 다중 권한이나 치매 당사자 사용성은 현재 완성 기능이 아니다.

가상 상황: 오전에 도서관에 가기로 말했지만 오후에 그 의도를 떠올리기 어렵다. 사용자는 기록에서 계획과 출처를 확인하고, 지금도 가고 싶은지 스스로 결정한다. 과거에 가기로 했다는 이유만으로 AI가 실행을 강요하지 않는다.

## 4. 현재 집중 범위

- 직접 입력·TXT·짧은 녹음 파일로부터 기록을 다루는 소프트웨어.
- 개인 저장소, 승인형 정보 추출, 검색, 하루 정리, 대화형 접근.
- 출처 분리와 변경 이력, 자기정보 승인, 외부 전송 확인.
- 음성과 자막으로 접근하는 대화 UI. 장부 작성과 같은 입력 부담을 줄이는 방향.

전체 흐름의 장기 목표는 휴대폰 녹음 → 전사·요약 → Drive → 정보 저장 → 저녁 정리 → 본인 반응과 다음 선택이다. 각 구간의 자동화 수준은 다르므로 현재 완전 자동 시스템으로 소개하지 않는다.

## 5. 범위를 늘리지 않기 위한 결정

| 항목 | 처리 |
|---|---|
| 전용 기기·웨어러블·배터리 최적화 | 현 단계 제외. 소프트웨어부터 검증 |
| 활동 중단에 따른 기능 악화 예방 | 보류 아이디어. 독립된 현재 목표나 효과 주장에 추가하지 않음 |
| 감정·애착 단서 활용 | 연구 질문으로 보존. 강렬한 감정 유발은 현재 기능·지표가 아님 |
| 치료·진단·치매 진행 예측 | 현재 범위 밖 |
| 기억 완전 복원·자아 복제 | 철학적 질문과 제품 기능을 구분 |
| 별도 웹 UI를 돌아다니는 고양이 스크립트 | 관련 실험 이력은 있으나 현재 상담 캐릭터와 통합 확인 안 됨 |

## 6. 인간 중심이라는 말의 실제 의미

사용자가 말한 ‘불편함’은 도구가 모든 판단을 대신하지 않고, 사람이 자신의 기억과 선택을 생각할 여지를 남긴다는 취지로 해석한다. 고통을 유발하거나 회상을 강제하는 요구가 아니다. 제품에서는 승인, 수정, 거절, 건너뛰기, 현재 선택 존중으로 표현한다.

“AI는 결국 사람의 생각을 돕는 도구”라는 방향은 대화 문구만으로 달성되지 않는다. 자동 저장 범위, 전송 전 확인, 자기정보 갱신 권한, 잘못된 기록을 고치는 경로까지 함께 설계해야 한다.
