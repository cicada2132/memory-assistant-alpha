# 연구 근거와 검증할 질문

확인일: 2026-10-22. 이 문서는 연구 자료와 설계 선택의 연결을 설명한다. 앱의 임상 효과를 주장하지 않는다.

## 1. 직접 확인한 핵심 자료

| 자료 | 자료의 성격 | 이 프로젝트에 적용한 해석 | 주장할 수 없는 것 |
|---|---|---|---|
| Richard Heersmink (2022), *Preserving Narrative Identity for Dementia Patients: Embodiment, Active Environments, and Distributed Memory*, Neuroethics 15, 8 | 철학·이론 논문 | 기억과 서사적 정체성을 외부 환경과의 관계에서 생각하는 출발점 | 본 앱이 기억이나 정체성을 보존한다는 실험적 증명 |
| Alzheimer's Society, *This is me* | 개인 중심 돌봄을 위한 정보 기록 도구 | 중요한 관계·장소·선호·생활 습관을 질문 주제로 참고 | AI 질문이 기억을 회복시킨다는 근거 |

Heersmink는 자전적 기억과 외부 자원의 관계를 논의하며 라이프로깅, 생애 이야기책, 기억 상자 등의 접근을 제시한다. 이 프로젝트는 이를 출처가 있는 개인 기록의 재접근이라는 설계 방향으로 해석했다. 구체적인 앱 질문 순서나 자동 추출 알고리즘은 프로젝트의 설계안이다.

This is me는 자신을 설명하기 어려운 사람의 배경, 중요한 사람·사건·장소, 선호와 습관을 전달하는 도구다. 프로젝트는 주제를 참고해 저녁 질문을 작성했다. 원본 서식의 복제·공식 인증·기관 협업을 뜻하지 않는다.

1. https://doi.org/10.1007/s12152-022-09479-x
2. https://www.alzheimers.org.uk/get-support/publications-factsheets/this-is-me

## 3. 연구 질문을 제품 요구사항으로 바꾸기

| 연구 질문 | 현재 구현 또는 설계 | 평가 방식 제안 |
|---|---|---|
| 과거 기록을 현재 상황 이해에 활용할 수 있는가? | 사건 검색·할 일 상태·지금 화면 | 합성 시나리오에서 올바른 기록 도달 여부 |
| 기록을 실제 기억으로 오인하게 하지 않는가? | 출처 라벨, 기록 근거로 답하도록 지시 | 출처 구별 과제·잘못된 단정 빈도 |
| 사용자 선택이 실제로 남아 있는가? | 승인·수정·거절·건너뛰기 | 각 경로 완료율과 조작 부담 |
| 사람의 선호를 AI가 임의로 고정하지 않는가? | 자기정보 제안 후 승인 | 승인 전 값 변경 0건인지 검사 |
| 기록과 본인 말이 다르면 어떻게 대응하는가? | 비대립적 대화 원칙·교정 기능 | 충돌 시나리오에서 강요·허구 생성 여부 |

## 4. 아직 답하지 않은 질문

감정·애착·친숙함이 어떤 조건에서 비교적 보존되는지, 어떤 기억 상실이 정체성에 영향을 주는지, 외부 기록을 자신의 기억으로 받아들이는 경계는 문헌과 사용자 연구가 더 필요하다. “치매는 감정 기억을 마지막까지 보존한다” 같은 보편 명제로 단순화하지 않는다.

감정 단서 추적과 하루 방향성 대화는 초기 아이디어로 보존한다. 현재 상담 프롬프트는 감정을 단정하거나 강하게 유도하지 않도록 되어 있다. 정서 반응 강도를 성공 지표로 삼지 않는다.

## 5. 연구 진행 순서

먼저 합성 데이터로 정확성·실패 대응·승인 경로를 평가한다. 이후 비임상 사용성 검토와 돌봄 전문가 검토를 거쳐, 당사자 참여 연구의 필요성과 절차를 별도 설계한다. 코드 테스트 통과, 사용성 향상, 임상적 효능은 서로 다른 증거 수준으로 보고한다.
