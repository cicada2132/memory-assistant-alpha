# 포트폴리오에 사용할 설명

아래 소개문은 현재 코드와 검증 범위를 바탕으로 작성한 초안이다. 기간·팀원 수·개인 기여 비율·실사용 성과는 확인되지 않아 만들지 않았다.

## 짧은 소개

**External Memory Alpha — 사용자의 선택을 보존하는 개인 기록·대화 보조 웹 앱**

치매 환자의 기억 공백을 돕기 위한 연구 기반 알파 프로젝트입니다. Google Apps Script와 Drive JSON으로 TXT 승인형 수집, 출처 기반 기록 검색, 자기정보 변경 승인, Gemini 하루 대화를 구현했습니다. AI가 기억을 대신 확정하지 않도록 원문·해석·사용자 선택을 구분하며, 현재 25개 모의 테스트를 통과했습니다.

## 상세 소개

이 프로젝트는 “개인 기록을 어떻게 저장할 것인가”에서 출발해 “저장된 기록을 어떤 권한과 맥락으로 다시 제시할 것인가”를 다룹니다. 분산 기억과 서사적 정체성 논의를 참고하여, 사용자가 외부 기록으로 자신의 상황을 이해하면서도 현재의 의사를 유지할 수 있는 구조를 설계했습니다.

현재 알파는 Drive에 업로드한 TXT를 자동 발견하고, 사용자에게 선택받은 문장을 정보 블록으로 저장합니다. 블록에는 출처·시각·할 일 상태·변경 이력이 연결됩니다. 기본 검색은 외부 생성 AI 없이 수행하고, Gemini 대화는 전송 미리보기와 동의를 거칩니다. 자기정보는 곧바로 덮어쓰지 않고 승인할 제안으로 관리합니다.

구현 과정에서 Galaxy TXT의 UTF-16 인코딩 문제, 자동화와 사용자 승인 사이의 절충, 직접 진술과 AI 해석의 분리, 문서와 실제 코드의 상태 불일치 등을 다뤘습니다. 현재 저장소의 모의 테스트 25개를 재실행해 통과를 확인했으며, 실제 연동·사용성·치매 관련 효과는 별도 검증 단계로 구분했습니다.

## 기술 면접에서 설명할 세 가지 사례

| 사례 | 문제 | 접근 | 남은 과제 |
|---|---|---|---|
| UTF-16 TXT | UTF-8로 읽은 녹음 앱 전사가 깨짐 | BOM 판별과 모의 TXT 검사 | 실제 기종·파일 변형 확인 |
| 자동화와 승인 | 자동 수집이 부정확한 정보를 그대로 굳힐 수 있음 | 발견→후보→선택 저장, 해시 기반 변경 감지 | 승인 부담·후보 재현율 측정 |
| 개인 기억 통제 | AI의 추정이 본인 정보로 덮어써질 수 있음 | 출처 유형, 제안/승인, 버전 충돌·교정 이력 | 실제 대화에서의 강요·기억 오염 평가 |

## 역할과 기여를 적는 기준

사용자의 문제 정의·설계 방향·범위 결정과 AI 도구를 활용한 코드·문서 작업을 구분해 설명한다. 기존 Mori 캐릭터 설정은 외부 자료의 수정본임을 표시한다. 직접 작성·검토·실행한 부분과 AI 보조로 생성한 부분을 실제 작업 이력에 맞춰 기술하며, 확인되지 않은 ‘전부 단독 개발’이나 실험 수행 실적을 추가하지 않는다.

## 소개에 쓰지 않을 성과

치매 치료·기억 복원, 임상 효과 검증, 완전 로컬 처리, 개인정보 유출 원천 차단, 모든 기록의 자동 의미 이해, 환각 제거 완료, 사용자 만족도 수치 등은 현재 근거가 없다.

## 제출 전 보완하면 좋은 증거

실제 합성 데이터 시연 영상, 커밋을 고정한 실행 결과, 검색 실패 사례와 수정 전후 비교, 개발자 자신의 기여 설명을 추가한다. 화면 이미지는 실제 앱에서 수집한 것임을 표시하고 목업과 구분한다.
